# Document Appraisal AI System

A multi-user Document AI and Records Management System.

## Core capabilities

- Pre-fed document metadata
- Document upload and storage
- Automatic metadata extraction
- Metadata-to-document matching
- Partial-match review
- Department categorization
- Document search
- Document retrieval
- Document viewing and downloading
- Document lifecycle management
- Multi-user access
- AI-assisted document appraisal

## Architecture

Frontend: Next.js + TypeScript  
Backend: Express + TypeScript  
Database: PostgreSQL + Prisma  
Storage: Server-side document storage

Docker is intentionally not used at this stage.
